# EasyGo 离线地图文件

## SD 卡路径

| 用途 | 模拟器宿主文件 | 固件路径 |
| --- | --- | --- |
| 默认地图（8×） | `4.Software/Simulator/SD/MAP/shenzhen.bin` | `S:/MAP/shenzhen.bin` |
| 七级地图 | `4.Software/Simulator/SD/MAP/shenzhen_z0.bin`–`shenzhen_z6.bin` | `S:/MAP/shenzhen_z0.bin`–`S:/MAP/shenzhen_z6.bin` |
| 地图层级索引 | `4.Software/Simulator/SD/MAP/shenzhen_levels.bin` | `S:/MAP/shenzhen_levels.bin` |
| 厕所 POI 索引 | `4.Software/Simulator/SD/MAP/shenzhen_toilets.bin` | `S:/MAP/shenzhen_toilets.bin` |

实体 SD 卡把这些文件放在根目录下的 `/MAP/`。模拟器将宿主 `SD`
目录映射为 `/SD/`，因此对应 LVGL 路径以 `/SD/MAP/` 开头。

## 地图图片

地图文件是 LVGL `LV_IMG_CF_TRUE_COLOR` 文件：

- 4 字节小端 LVGL 图片头。
- 720×492 RGB565 像素，像素按小端存储。
- 单文件大小为 708,484 字节。
- 地图图片仅用于显示，不能作为可查询的 POI 数据。

240×164 的地图视口显示 720×492 大画布的一部分。初始滚动位置为
`(240, 164)`，即居中显示；用户可在视口中双向拖动，最大有效滚动范围为
X 方向 `0–480`、Y 方向 `0–328`。路线、当前位置和目标标记必须放在同一个
地图内容层中，随画布一起移动；缩放按钮、行政区标签和署名应放在视口之外
的固定覆盖层。

`shenzhen.bin` 是层级 3（8×），`shenzhen_z3.bin` 是内容相同的别名。
七级比例为 1×、2×、4×、8×、16×、32×、64×。每一级都使用相同的
720×492 画布尺寸和 240×164 视口，因此切换文件时可以保留当前滚动位置。

不要对 SD 文件源调用 `lv_img_set_zoom()`：LVGL 按行解码文件，而图片变换
需要完整像素缓冲。当前实现通过切换预生成层级获得缩放效果。

## `shenzhen_levels.bin`

该文件把每一级栅格地图绑定到 WGS84 坐标。坐标均为角度乘以
10,000,000，整数使用小端字节序。

### 头部（64 字节，版本 2）

| 偏移 | 类型 | 含义 |
| ---: | --- | --- |
| 0 | `char[8]` | 魔数 `EGMAPL2\0` |
| 8 | `uint16` | 格式版本，当前为 `2` |
| 10 | `uint16` | 头部长度，当前为 `64` |
| 12 | `uint32` | 层级数，当前为 `7` |
| 16 | `uint32` | 层级记录长度，当前为 `32` |
| 20 | `uint32` | 坐标比例，当前为 `10000000` |
| 24 | `int32` | 模拟焦点纬度 |
| 28 | `int32` | 模拟焦点经度 |
| 32 | `uint16` | 画布宽度，当前为 `720` |
| 34 | `uint16` | 画布高度，当前为 `492` |
| 36 | `uint16` | 视口宽度，当前为 `240` |
| 38 | `uint16` | 视口高度，当前为 `164` |
| 40 | `uint16` | 画布水平内容边距，当前为 `24` |
| 42 | `uint16` | 画布垂直内容边距，当前为 `24` |
| 44 | `int32` | 初始滚动 X，当前为 `240` |
| 48 | `int32` | 初始滚动 Y，当前为 `164` |
| 52 | `uint32` | 所有层级记录的 CRC32 |
| 56 | `uint32` | OSM 快照日期，格式 `YYYYMMDD` |
| 60 | `uint32` | 保留，当前为 `0` |

### 层级记录（32 字节）

| 偏移 | 类型 | 含义 |
| ---: | --- | --- |
| 0 | `uint8` | 层级编号 |
| 1 | `uint8[3]` | 保留 |
| 4 | `uint32` | 相对比例乘以 1000 |
| 8 | `int32` | 画布南边界纬度 |
| 12 | `int32` | 画布西边界经度 |
| 16 | `int32` | 画布北边界纬度 |
| 20 | `int32` | 画布东边界经度 |
| 24 | `uint32` | 水平毫米/像素 |
| 28 | `uint32` | 垂直毫米/像素 |

经度投影到 X 时使用西/东边界与水平内容边距；纬度投影到 Y 时使用
北/南边界并反转 Y 方向。MCU 上使用 64 位中间值。得到的是大画布坐标；
换算到屏幕坐标时还要减去 LVGL 当前滚动偏移。

## `shenzhen_toilets.bin`

所有整数使用小端字节序，经纬度为 WGS84 角度乘以 10,000,000。

### 头部（48 字节）

| 偏移 | 类型 | 含义 |
| ---: | --- | --- |
| 0 | `char[8]` | 魔数 `EGTOIL1\0` |
| 8 | `uint16` | 格式版本，当前为 `1` |
| 10 | `uint16` | 头部长度，当前为 `48` |
| 12 | `uint32` | 记录数 |
| 16 | `uint32` | 记录长度，当前为 `64` |
| 20 | `uint32` | 坐标比例，当前为 `10000000` |
| 24 | `uint32` | OSM 快照日期，格式 `YYYYMMDD` |
| 28 | `int32` | 南边界纬度 |
| 32 | `int32` | 西边界经度 |
| 36 | `int32` | 北边界纬度 |
| 40 | `int32` | 东边界经度 |
| 44 | `uint32` | 所有记录字节的 CRC32 |

### 记录（64 字节）

| 偏移 | 类型 | 含义 |
| ---: | --- | --- |
| 0 | `uint64` | OSM 对象 ID |
| 8 | `int32` | 纬度 |
| 12 | `int32` | 经度 |
| 16 | `uint16` | 属性标志 |
| 18 | `uint8` | OSM 类型：节点 `0`、道路对象 `1`、关系 `2` |
| 19 | `uint8` | UTF-8 名称字节数 |
| 20 | `char[44]` | UTF-8 名称，以零填充 |

属性位依次表示：无障碍 yes/limited/no（位 0–2）、收费 yes/no（位 3–4）、
男女通用 yes（位 5）、存在开放时间（位 6）、存在受限访问值（位 7）。
缺少标志表示“未知”，不是“否”。

该索引只反映下载时 OSM 中已标注的厕所，不证明实时开放、无障碍、安全或
数据完整性。
